# IoT-Based-Home-Security-System-Using-ESP8266-and-KiwisIoT
IoT-Based Home Security System using NodeMCU ESP8266 and a PIR motion sensor with real-time motion detection and remote monitoring through the KiwisIoT platform.
IoT-Based Home Security System Using ESP8266 and KiwisIoT
About the Project
The IoT-Based Home Security System is an IoT-based smart home project designed to detect unauthorized movement and improve home security through real-time monitoring.

Using a NodeMCU ESP8266 microcontroller and a PIR motion sensor, the system detects human movement in the monitored area and sends sensor data to the KiwisIoT platform through Wi-Fi. Users can remotely monitor motion detection status through an online dashboard and receive alerts when movement is detected, if notifications are configured.

By integrating KiwisIoT, this project demonstrates a simple and effective approach to smart home security, motion detection, remote monitoring, and IoT-based safety applications.
